# Lubin Mendez Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript. It showcases projects, technical skills, and contact information through a clean and modern interface.

## Features

* Responsive design for mobile, tablet, and desktop
* Hero section with typing effect
* About section
* Projects section with live demos and GitHub repositories
* Skills section
* Contact form powered by Formspree
* Responsive navigation with mobile menu
* Social links for LinkedIn, GitHub, and email
* Component-based CSS structure

## Projects

The portfolio features interactive web projects including:

* Rock Paper Scissors
* Calculator
* Stopwatch

## Technologies

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Formspree
* GitHub Pages

## Project Structure

```text
portfolio-lubin-mendez/
├── index.html
├── components/
├── styles/
├── assets/
└── README.md
```

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No installation or additional dependencies are required.
